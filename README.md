# gotify-MQL4
Instant notification of new trades using [gotify](https://gotify.net/) server with zero cost

# Setup

1. If you're running gotify on a port that's not 80, you can use a free[ Cloudflare Quick Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)
2. Compile the code in MetaEditor with your Gotify app token
3. Go to Tool s-> Options -> Allow DLL imports, and Allow WebRequest for listed URL: (Add in your Cloudflare URL or Gotify service running on port 80)
4. Press OK, drag the EA onto any position and check the Experts tab to make sure it's working
